## Topics

* `arrays/` — Array problems
* `strings/` — String problems
* `trees/` — Tree problems
* `graphs/` — Graph problems
* `dynamic-programming/` — Dynamic Programming problems

## Goal

Build strong problem-solving skills and develop a solid understanding of common data structures and algorithms through consistent practice.

## Platform

Problems are primarily solved on [LeetCode](https://leetcode.com/problemset/).

Each solution is written and tested by me.
